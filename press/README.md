Vérification : 3 octobre 2026. Recherche partielle, pas une validation de tous les visuels du catalogue.

## Photo intégrée

La Voile : terrasse de La Réserve Ramatuelle, photographiée par Grégoire Gardette. Photo observée et identifiée dans la [photothèque officielle](https://www.michelreybierhospitality.com/fr/press-image-gallery/), filtre « LA RÉSERVE RAMATUELLE – HOTEL, SPA AND VILLAS » ; nom affiché `LRR_Property_Interior_LaVoile_Terrasse_ByGregoireGardette.jpg`.

Les [conditions presse du groupe](https://www.michelreybierhospitality.com/fr/press-landing/) permettent la publication des visuels de sa galerie dans le cadre d’une référence à l’hôtel ou au groupe. La fiche présente précisément La Voile à La Réserve Ramatuelle. Crédit conservé ; aucune retouche IA. Cette permission conditionnelle n’est pas une licence générale « libre de droits ». Les fichiers haute résolution demandent un compte ; la prévisualisation publique de 1620 × 1080 est utilisée ici.

La photo est servie depuis le site officiel : elle n’est pas incluse comme fichier local dans cette archive. Son affichage dépend donc de ce serveur. Les photos de contexte de Ramatuelle restent disponibles dans le catalogue mais ne sont plus la galerie de La Voile.

Les PDF ont été repérés en ligne. Les téléchargements tentés ici n’ont pas produit de fichiers accessibles dans le projet ; ils ne sont donc pas présentés comme récupérés. Pour les enregistrer localement sous Windows, à la racine du projet :

```powershell
npm run press:download
```

Le script enregistre les PDF dans `press/dossiers/`, avec un reçu détaillant les réussites et échecs. Il ne publie pas les dossiers ni leurs images. Un téléchargement ne vaut pas autorisation de réutilisation des photographies. `downloads.json` conserve les liens exacts.
