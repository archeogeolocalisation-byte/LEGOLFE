# Approved LEGOLFE / SAINT-TROPEZ logo

The second logo proposal approved on 21 October 2026 is used in the shared header and footer. The transparent production asset was prepared with image generation from the approved image, then trimmed and exported as lossless WebP at 1200 × 274 pixels. The source file is `public/media/brand/legolfe-saint-tropez-v2.webp`.

The header uses a compact responsive width; the footer uses a larger width. Dark backgrounds use a white CSS treatment of the same transparent asset. Intrinsic dimensions reserve its space. The image and home link have accessible names, and the home destination follows the current locale. No new client-side script or external asset service is required.

Existing WebKit footer checks also verify image loading in the header/footer, light and dark pages, desktop/mobile screenshots, and header link bounds at 320px.
